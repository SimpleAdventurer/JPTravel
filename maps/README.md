# 역내청 성지순례 지도 2027 (도쿄·치바·가나가와) — 구글 마이맵용 데이터

『やはり俺の青春ラブコメはまちがっている。』(역내청) 1기·속·완·OVA·원작 라이트노벨의 성지를 한 지도에 모은 데이터다. 2027년 1~3월 여행을 기준으로 2026-10-20에 정리했다.

- 총 **169개 지점**을 **10개 레이어**로 나눴다. 구글 마이맵의 레이어 한도(10개)에 딱 맞춘 것이다.
- 교토(속 1·2화 수학여행)는 전부 뺐다. 범위 밖 장소(群馬의 千葉村, 埼玉의 サイゼリヤ新座栗原店)는 지도에 싣지 않고 연구 노트에만 적었다.
- **개인 주거지의 정확한 좌표는 싣지 않았다**(아래 「개인정보 원칙」).

## 구글 마이맵으로 가져오기

### 방법 A — 레이어별 KML 10개(권장)
1. PC 브라우저에서 <https://www.google.com/mymaps>에 접속해 **「새 지도 만들기」**를 누른다.
2. 왼쪽 위 「제목 없는 지도」를 눌러 지도 이름을 정한다(예: 역내청 성지순례 2027).
3. 처음부터 있는 「제목 없는 레이어」 아래의 **「가져오기」**를 누르고 `layers/01_inage_kaigan.kml`을 올린다.
4. **「레이어 추가」**를 눌러 새 레이어를 만들고, 그 레이어의 「가져오기」로 `02_…kml`을 올린다.
5. 4번을 `10_lodging.kml`까지 반복한다. 레이어 이름이 파일명으로 들어오면 레이어 메뉴(⋮)에서 아래 표의 이름(①~⑩)으로 바꾼다.
6. 핀 이름 앞의 `L01-01` 같은 ID는 설명문 속 교차 참조(예: 「L07-11 참고」)를 찾을 때 쓴다. 왼쪽 레이어 목록이 ID 순서로 나오므로 바로 찾을 수 있다.
7. 휴대폰에서는 Google 지도 앱의 **「저장됨 → 지도」**에 같은 계정으로 만든 마이맵이 나온다. 동행자에게는 「공유」에서 링크를 보내면 된다.

### 방법 B — CSV 한 파일
1. 새 지도를 만들고 「가져오기」에서 `oregairu_pilgrimage_2027.csv`를 올린다.
2. 「위치 표시 열 선택」에서 **`lat` = 위도, `lng` = 경도**에 체크한다.
3. 「마커 제목 열 선택」에서 **`name_ko`**를 고른다.
4. CSV는 레이어 1개로 들어간다. 레이어의 「균일한 스타일」 → **「그룹화 기준: `layer`」**로 바꾸면 레이어별로 색을 나눌 수 있다. `status_2027`이나 `confidence`로 묶어도 된다.
5. 엑셀에서 바로 열면 한글·일본어가 깨질 수 있다. 구글 스프레드시트로 열거나, 엑셀의 「데이터 → 텍스트/CSV」에서 UTF-8을 지정해 가져온다.

### 방법 C — 전체 KML 한 파일
`oregairu_pilgrimage_2027_all.kml`은 Google Earth(웹·Pro)에서 열면 폴더 10개가 그대로 보인다. 마이맵에 이 파일 하나만 가져오면 폴더 구성이 레이어로 유지되지 않을 수 있으니, 마이맵에서는 방법 A를 쓰자.

### CSV 열 설명
| 열 | 내용 |
|---|---|
| `id` | 지점 ID(L01-01 형식, 레이어 번호 + 일련번호) |
| `layer` | 레이어 이름(①~⑩) |
| `name_ko` / `name_ja` | 한국어 이름 / 일본어 이름(현지 표기·검색용) |
| `lat`, `lng` | WGS84 위도·경도(소수 6자리) |
| `work_episode` | 등장 회차(예: 1기 9화 / 속 13화 / 완 11화 / 원작 n권) |
| `scene_ko` | 무슨 장면인지, 왜 중요한지(1~2문장) |
| `status_2027` | 2027년 1~3월 기준 상태 + 짧은 메모(휴무일·공사·가격 등) |
| `confidence` | 장소 비정의 신뢰도(확정·유력·추정) |
| `visit_tip_ko` | 가는 법·촬영 팁·매너 |
| `google_maps_url` | 구글 지도 바로가기(`https://www.google.com/maps/search/?api=1&query=위도,경도`) |
| `sources` | 출처 약어·링크와 좌표 출처(「좌표출처: …」) |

## 개인정보 원칙
- 팬들이 유키노 맨션 모델로 꼽는 타워맨션, 유이의 집·맨션 후보, 완 4화 신문판매점 자리(2024~2026년 개인 주택으로 바뀜), 比企谷家 같은 **개인 주거지의 정확한 좌표·건물명은 싣지 않았다.**
- 대신 가장 가까운 **공공 지점**(공원·공공 도로·교차로)을 실었고, 설명문에 그렇게 적었다: L01-07·L01-08(中高浜公園·통학로), L01-11(유이 귀갓길 교차로), L03-17·L03-18(打瀬 공공 보도).
- 지도의 모든 지점은 위 주거지 좌표에서 **40 m 이상** 떨어져 있도록 검사했다(가장 가까운 것이 약 43 m).
- 현지에서는 단지·로비·엔트런스에 들어가지 말자. 건물·창문·거주자·학생 얼굴을 찍지 말고, 건물명·주소를 SNS에 태그하지 않는다. 일본·한국 팬들이 지켜 온 관행이다.

## 좌표 품질과 검증
- 좌표는 우선순위대로 정했다. ① 블로거가 현장 비교한 팬 지도 핀 → ② 여러 지도가 일치하는 핀 → ③ 공식 점포 좌표·食べログ 지도 마커 → ④ OSM(Nominatim) → ⑤ 국토지리원(GSI) 주소검색. 어느 것을 썼는지는 `sources` 열의 「좌표출처」에 적었다.
- 레이어마다 정해 둔 범위 상자 안에 들어오는지 모든 지점을 검사했다.
- 모든 지점을 GSI 역지오코더로 조회해 시·구 코드가 예상과 맞는지 확인했다(169/169 일치).
- 같은 대상을 가리키는 30 m 이내 핀은 하나로 합쳤다. 서로 다른 곳인데 30 m보다 가까운 쌍은 하나뿐이고 노트에 적었다(옛 ミスド 자리–らしんばん 千葉店 약 28 m).
- 내려받은 팬 지도 핀 511개를 모두 대조했다.
  - 26개: 중복 지도(俺ガイルマニュアル 회차순판)
  - 89개: 범위 밖(교토 79·群馬 10)
  - 범위 안 396개 중 370개: 지점에 병합
  - 26개: 사유지·소멸·근거 부족·범위 밖(埼玉)이라 이유를 적고 제외
