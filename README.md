### 요약

- **거점**: 海浜幕張(가이힌마쿠하리) 연박. 성지 대부분이 京葉線·모노레일로 4~15분 거리인 稲毛海岸·海浜幕張·千葉みなと·千葉駅에 몰려 있다.
- **추천 날짜**: 2027-02-21(일)~02-26(금) 5박6일. 4박5일이면 02-08(월)~02-12(금).
- **꼭 갈 곳**: 稲毛陸橋(완 11화), 葛西臨海公園(속 13화), 美浜大橋(속 8화), THE SURF·いなげの浜(완 12화), 稲毛高校 후문·中高浜公園.
- **원작 15주년 치바 캠페인**(2026-11-21~2027-03-31) 스탬프랠리 6곳을 일정에 넣었다.
- 학교와 개인 주거지는 공공 도로에서만 짧게 본다. 주거지의 건물명·주소·좌표는 싣지 않았다.

출발 전에는 계획서 10-2의 체크리스트로 아직 발표되지 않은 정보(스탬프랠리 세부, 디즈니 3월 요금, 稲毛高校 졸업·폐교식 날짜 등)를 다시 확인하자.
